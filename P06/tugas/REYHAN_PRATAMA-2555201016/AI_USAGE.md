# AI Usage - P06

## Penggunaan AI

Dalam pengerjaan praktikum P06, saya menggunakan ChatGPT sebagai alat bantu untuk memahami materi dan menyelesaikan beberapa bagian program Python.

## Bentuk Bantuan AI

1. Menjelaskan materi inheritance, overriding, dan polymorphism.
2. Membantu memberikan contoh kode class `Traktor`, `PompaAir`, dan `Perontok`.
3. Membantu memperbaiki kode `BarisSewa` agar perhitungan biaya tambahan setiap alat berjalan dengan benar.
4. Membantu mencari penyebab beberapa pengujian yang gagal.
5. Membantu memperbaiki format kode menggunakan Ruff.
6. Memberikan arahan menjalankan pengujian dan pemeriksaan program.

## Proses Pengerjaan

Saya mengikuti arahan yang diberikan ChatGPT, menyalin dan menyesuaikan kode ke dalam proyek, kemudian menjalankan perintah pengujian melalui PowerShell. Ketika ditemukan kesalahan, saya mengirimkan hasilnya untuk dibantu mencari dan memperbaiki penyebabnya.
