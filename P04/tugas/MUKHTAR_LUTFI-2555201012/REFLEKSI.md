# Refleksi Praktikum P04

Selama mengerjakan praktikum P04, saya belajar memahami penggunaan class dan object dalam pemrograman berorientasi objek (PBO). Saya juga mempelajari penggunaan atribut, method, property, static method, dan class method.
Pada tugas Kios, saya belajar membuat sistem sederhana untuk mengelola produk, seperti kode barang, nama produk, harga, dan stok. Pada praktikum AlatTani, saya belajar menerapkan validasi tarif sewa, menghitung biaya sewa, menghitung denda keterlambatan, serta membuat objek dari data CSV.
Kesulitan yang saya alami adalah memahami penerapan setiap konsep PBO dan memastikan program berjalan sesuai ketentuan. Untuk mengatasinya, saya mencoba memeriksa kembali kode, menjalankan pengujian, dan memperbaiki kesalahan yang ditemukan.
Dari praktikum ini, saya menjadi lebih memahami bahwa penggunaan class dan object dapat membuat kode lebih terstruktur, mudah dikembangkan, dan lebih mudah diuji.
Ke depannya, saya ingin lebih banyak berlatih agar semakin terbiasa menerapkan konsep PBO dalam membuat program.
