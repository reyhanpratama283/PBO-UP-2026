# AI Usage Documentation - P04

Dokumen ini menjelaskan penggunaan asisten AI dalam membantu penyelesaian tugas Pemrograman Berorientasi Objek (P04).

## Peran Asisten AI
Asisten AI digunakan sebagai kolaborator teknis untuk:
1. Membantu merancang struktur modular (`src/model/`) sesuai dengan ketentuan tugas.
2. Membantu menyusun file pengujian (*test suite*) dengan `pytest` untuk memastikan kode memenuhi ambang batas minimal fungsi uji.
3. Membantu proses debugging dan penyesuaian penanganan error (*exception handling*) pada kelas-kelas model (`AlatTani`, `Alamat`, `Penyewa`).
